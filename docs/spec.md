# ImagePalace 機能仕様書

> 最終更新: 2026-03-17

---

## サービス概要

テキスト中心の学習に違和感を持つビジュアルシンカーのための、イメージ特化型学習支援サービス。
単語や概念をAI生成画像に変換し、視覚的に記憶しやすいカード形式で管理・想起する。

---

## 用語集

| 用語 | 定義 |
|-----|------|
| カード | 単語 + AI生成画像 のペア。学習の最小単位 |
| 想起 | 必要なときに知識を思い出すこと。このサービスが最終的に支援したい体験 |
| 画像キャッシュ | 同一単語に対して2回目以降は保存済み画像を返す仕組み。API コスト削減が目的 |
| 生成ステータス | カードの状態。`pending`（生成待ち）→ `processing`（生成中）→ `completed`（完了）/ `failed`（失敗） |
| Solid Queue | Rails 8 標準の非同期ジョブ実行基盤（ActiveJob経由）。PostgreSQL をキューに使用 |
| 無料枠 | MVP における生成枚数の上限。上限到達後は新規作成を停止する |

| 機能 | 説明 | 優先度 |

| ポーリング更新 | フロントエンドが生成完了を定期確認 | Must |

## 画像生成フロー（概要）

1. ユーザーが単語を入力し「生成」ボタンを押す
2. バックエンドが同一単語のキャッシュを確認する
   - **キャッシュあり** → 即座にカードを返す（API呼び出しなし）
   - **キャッシュなし** → ジョブをキューに積み、`pending` 状態のカードを返す
3. バックグラウンドのジョブが OpenAI Images API を呼び出す
4. 生成された画像を Cloudflare R2 に保存し、カードのステータスを `completed` に更新する
5. フロントエンドのポーリングが完了を検知し、画像を表示する

Cloudflare CDN 経由で配信。R2 直配信は禁止。

## MVP 後の機能（優先度順）

| 機能 | 概要 |
|-----|------|
| デッキ管理 | カードをグループ化して整理 |
| タグ・カテゴリ | 横断的な分類と検索 |
| 意味・説明の自動生成 | 単語の補足情報をAIで生成 |
| 空間ボード | カードを自由配置してマインドマップ的に整理 |
| 課金機能 | Stripe + 生成枚数制限のサブスクリプション |
| 共有機能 | 公開カード・コレクション販売 |
| インポート / エクスポート | CSV・Markdown の取り込み・書き出し |
| クイズ機能 | 想起強化のためのフラッシュカード形式テスト |

## 制約・非機能要件

| 項目 | 内容 |
|-----|------|
| 生成コスト | 同一単語のキャッシュ再利用で OpenAI API コストを抑制 |
| 生成待機時間 | 非同期処理のため、生成完了まで数秒〜数十秒かかる |
| 無料枠の上限 | MVP では1ユーザーあたり月100枚までに制限し、超過後は新規作成を停止する |
| データ所有 | ユーザーのカードは当該ユーザーのみアクセス可能（他ユーザーのカードは参照不可） |
| 画像配信 | ストレージ直配信禁止。CDN 経由のみ |
| API キー | OpenAI API キーはバックエンドのみに設定。フロントエンドから直接呼び出し禁止 |
