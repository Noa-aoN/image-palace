# Roadmap

実装予定の機能・計画を管理するフォルダ。

> **decisions/ との違い**
> - `decisions/` → 技術的な意思決定ログ（過去形・変更禁止）
> - `roadmap/` → 将来の実装計画（更新・追記OK）

---

## 今後のファイル構成（例）

```
roadmap/
├── README.md         # このファイル
├── mvp-post.md       # MVPリリース後に実装する機能
└── features/         # 個別機能の詳細設計
```

MVP後の機能一覧は `docs/spec.md` の「MVP 後の機能」セクションを参照。
