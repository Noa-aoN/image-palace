# Palace デザインシステム

## カラーパレット

| 用途 | 変数名 | 値 |
|-----|-------|-----|
| 背景（メイン） | `ivory` | `#F4EFE6` |
| 背景（サブ） | `ivory-dark` | `#ECE5D8` |
| アクセント | `palace` | `#C6A75E` |
| テキスト（メイン） | — | `#111111` |
| テキスト（サブ） | — | `#4A4A4A` |
| ボーダー | — | `#E3E6EA` |

> アクセントカラー（`palace` ゴールド）は枠線・アイコン・強調要素のみに使う。
> 背景やテキストの多用禁止。

## スペーシング

黄金比ベースの spacing 変数（`phi-1` 〜 `phi-6`）を Tailwind の extend に定義して使う。

## コンポーネント方針

- **shadcn/ui コンポーネントを優先**して使う。独自実装は shadcn にないものだけ
- アニメーション: **Framer Motion**
- LP スクロール演出: **Lenis**（滑らかなスクロール）

## ルール

- `components/ui/` は shadcn/ui ベースの基本 UI のみ
- `components/features/` にドメイン固有コンポーネントを置く
- `"use client"` は最小限。インタラクション必須の箇所のみ
- レスポンシブ: モバイルファーストで `md:` / `lg:` を使う
